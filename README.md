# D365FO

A React + Vite app.

## Run locally

```powershell
npm install
npm run dev
npm run build
npm run preview
```

`src/main.jsx` is the compiled bundle from saved HTML. `src/style.css` contains the extracted styles.

The local `/actions` API and `data/records.json` are for local development only and are ignored by Git; they are not included in the repository.
